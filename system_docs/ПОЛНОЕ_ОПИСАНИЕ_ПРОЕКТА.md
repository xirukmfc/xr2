## 🎯 Позиционирование и целевая аудитория

### О продукте

**xR2** - это enterprise-платформа для централизованного управления AI промптами, предназначенная для продуктовых команд и пользователей систем автоматизации. Основная идея: вместо хардкода промптов в коде каждого приложения - централизованное управление через API, с версионированием, аналитикой и A/B тестированием.

**Веб-сайт:** https://xr2.uk  
**Документация:** https://docs.xr2.uk/  
**Production:** https://xr2.uk

### Целевая аудитория

#### 1. Product Managers и Product Owners
- Управление AI-функциональностью без деплоя приложений
- Быстрые итерации над промптами (в 10 раз быстрее)
- Измерение эффективности AI-фич через ROI-аналитику
- Data-driven принятие решений о промптах

#### 2. Продуктовые команды
- Совместная работа над промптами как над продуктовыми features
- Централизованное управление промптами всех проектов компании
- Командная разработка и тестирование промптов
- Переиспользование промптов между проектами

#### 3. Пользователи систем автоматизации (Make, n8n, Zapier, Bubble.io, Airtable и др.)
- **"Чайники AI"** - пользователи без глубоких знаний AI
- Нужны удобные инструменты для управления промптами
- Визуальное управление без программирования
- Интеграция с любимыми no-code платформами

#### 4. Компании с несколькими продуктами
- Единая точка управления промптами всех продуктов
- Переиспользование промптов между проектами
- Централизованная аналитика по всем продуктам
- Контроль затрат на AI по всей компании

### Основные проблемы, которые решает xR2

**❌ До xR2:**
- Промпты разбросаны по коду разных приложений
- Невозможно быстро тестировать изменения промптов без деплоя
- Нет понимания ROI от AI-функциональности
- Сложно проводить A/B тесты промптов
- Нет централизованного контроля затрат на AI
- Невозможно отследить эффективность промптов в реальном времени

**✅ С xR2:**
- Все промпты в одном месте с версионированием
- Мгновенные обновления промптов без деплоя приложений
- Детальная аналитика использования и ROI
- Встроенные инструменты для A/B тестирования
- Централизованный контроль затрат и квот
- Real-time мониторинг эффективности промптов

## 🚀 Общее описание системы

xR2 - это enterprise-решение для product owners и команд разработки, которые хотят централизованно управлять всеми AI промптами во всех своих проектах и кодовых базах. Платформа обеспечивает полный контроль над жизненным циклом промптов - от разработки до production развертывания, с возможностью мониторинга использования и анализа эффективности в реальном времени.

### Ключевые преимущества для продуктовых команд

- 🎯 **Центральное управление**: Все промпты всех проектов в одном месте
- 🔄 **API-as-a-Service**: Подключение любых приложений через REST API
- 📊 **Business Intelligence**: Детальная аналитика использования и ROI
- 🚀 **Zero-code решение**: Управление промптами без изменения кода приложений
- 🔒 **Enterprise Security**: Полная изоляция данных между проектами
- ⚡ **Production-Ready**: Стабильная работа в Docker с enterprise-grade архитектурой

#### Версионирование и жизненный цикл
- **Git-like workflow**: Draft → Testing → Production с approval процессом
- **Automatic changelog generation**: Детальное отслеживание изменений между версиями

### 2. API-as-a-Service для разработчиков

#### REST API Endpoints
- **GET /api/v1/get-prompt/{slug}**: Получение промпта для приложений
  - Version-aware responses с automatic production version serving
  - Rate limiting и usage logging для analytics
  - Multi-format support (JSON, plain text, structured responses)
  - Real-time updates без app redeployment
  
- **POST /api/v1/events**: Отслеживание custom events привязанных к trace_id от промпта
- **POST /api/v1/events/batch**: Batch processing до 100 событий за раз

#### Особенности API
- **Multiple environment support**: Dev/Staging/Production environments
- **Rate limiting**: Настраиваемые лимиты по пользователям и проектам
- **API key management**: Безопасное управление доступом к промптам
- **Real-time updates**: Мгновенное обновление промптов без редеплоя приложений
- **Multi-format response**: JSON, plain text, structured data
- **Trace ID система**: Каждый промпт возвращает уникальный `trace_id` для отслеживания

### 3. A/B тестирование промптов

#### Функционал A/B тестирования
- **Простое A/B тестирование**: Сравнение двух версий промпта (A и B)
- **Автоматическое распределение трафика**: 50/50 split между версиями
- **Статистическая значимость**: Автоматический расчет confidence level
- **Conversion tracking**: Привязка к conversion funnels для измерения эффективности
- **Request limits**: Настраиваемые лимиты запросов для завершения теста
- **Real-time результаты**: Live обновление статистики во время теста

#### Как работает A/B тестирование
1. Создание двух версий промпта (A - контрольная, B - тестовая)
2. Настройка A/B теста с указанием success event (funnel)
3. Автоматическое распределение трафика 50/50
4. Отслеживание conversion events через trace_id
5. Автоматический расчет статистической значимости
6. Выбор победителя на основе данных

#### API Response с A/B тестом
```json
{
  "slug": "onboarding",
  "system_prompt": "...",
  "trace_id": "evt_abc123_1634567890_xyz",
  "ab_test_id": "test_123",
  "ab_test_name": "Tone Experiment",
  "ab_test_variant": "A"
}
```

### 4. Система событий и аналитики

#### Event Tracking & Attribution System
xR2 предоставляет мощную систему для привязки бизнес-событий к конкретным промптам, позволяя product owners измерять реальную эффективность AI-функциональности.

#### Event Definitions - Схемы событий
- **Определение структуры событий**: Required и optional поля
- **Валидация данных**: Автоматическая проверка соответствия схеме
- **Категоризация**: Группировка событий по категориям (conversion, engagement, etc.)
- **Типизация полей**: String, number, boolean, date и другие типы

Пример схемы события:
```json
{
  "event_name": "user_signup",
  "category": "conversion",
  "required_fields": [
    {"name": "user_id", "type": "string"},
    {"name": "source", "type": "string"}
  ],
  "optional_fields": [
    {"name": "utm_campaign", "type": "string"},
    {"name": "revenue", "type": "number"}
  ]
}
```

#### Conversion Funnels (Воронки конверсии)
- **Построение воронок**: От промпта до целевого действия
- **Источники воронок**: 
  - Prompt Requests (пользователи, получившие промпт через API)
  - Event (пользователи, вызвавшие определенное событие)
- **Многошаговые воронки**: Последовательность событий от начала до конверсии
- **Conversion window**: Настраиваемое время ожидания конверсии (по умолчанию 24 часа)
- **Метрики**: Count (количество) или Sum (сумма значений поля)

Пример воронки:
```
Step 1: product_viewed      → 1,000 users (100%)
Step 2: added_to_cart       →   400 users (40%)  ↓60% drop
Step 3: checkout_started    →   200 users (50%)  ↓50% drop
Step 4: purchase_completed  →   150 users (75%)  ↓25% drop
```

#### Продуктовые кейсы использования аналитики

**📈 A/B Testing промптов**
- Сравнение conversion rate между разными версиями welcome промптов

- Оценка effectiveness различных onboarding сценариев

**💰 ROI Analysis**

**🔄 Funnel Optimization**
- Построение conversion funnels от промпта до target action
- Identification drop-off points в user journey

**🎯 Feature Impact Measurement**
- Измерение влияния новых AI-features на key metrics
- Tracking user retention после AI-powered interactions
- Validation продуктовых гипотез через data

## 🏗 Архитектура и технический стек

### Backend Stack

#### Core Technologies
- **Python 3.11+**: Modern async/await support
- **FastAPI 0.110.0**: High-performance async API framework (production-stable version)
- **SQLAlchemy 2.0**: Async ORM с relationship management
- **Alembic**: Database migrations для continuous deployment
- **PostgreSQL 15**: Enterprise-grade database с advanced indexing
- **Redis 7**: Intelligent caching и session management
- **Pydantic**: Data validation и serialization
- **SQLAdmin 0.16.1**: Enterprise admin interface (stable version)

#### Architecture Patterns
- **Async/Await**: Полностью асинхронная архитектура для высокой производительности
- **Dependency Injection**: Чистая архитектура с dependency injection
- **Repository Pattern**: Абстракция доступа к данным
- **Service Layer**: Бизнес-логика отделена от API слоя

### Frontend Stack

#### Core Technologies
- **Next.js 15**: React framework с SSR и App Router
- **React 19**: Modern React с hooks и concurrent features
- **TypeScript**: Type safety для надежности кода
- **Tailwind CSS**: Utility-first CSS framework
- **Monaco Editor**: Code editor для промптов (тот же, что в VS Code)
- **Chart.js / Recharts**: Data visualization для аналитики
- **shadcn/ui**: Современные UI компоненты

#### Frontend Features
- **Server-Side Rendering (SSR)**: Быстрая загрузка страниц
- **Client-Side State Management**: React Context и hooks
- **Real-time Updates**: Live обновление статистики через polling
- **Responsive Design**: Mobile-first подход
- **Dark/Light Themes**: Персонализация интерфейса

### Database Schema

#### Core Models

**Users & Authentication**
- `User`: Пользователи с JWT и Google OAuth
- `Workspace`: Multi-tenant изоляция для команд
- `WorkspaceMembers`: Role-based access control
- `RefreshToken`: JWT refresh tokens для безопасности

**Prompts & Versions**
- `Prompt`: Контейнер промпта с lifecycle management (Draft/Active/Archived)

- `Tag`: Color-coded categorization system

**LLM Providers**
- `LLMProvider`: Конфигурация провайдеров (OpenAI, Anthropic, Google, etc.)

**API & Security**
- `ProductAPIKey`: Encrypted external API access keys
- `ProductAPILog`: Comprehensive request/response logging
- `UserAPIUsage`: Real-time usage tracking и quota enforcement

**Analytics & Events**
- `EventDefinition`: Схемы событий с валидацией required/optional полей
- `PromptEvent`: Отслеживание custom events с привязкой к trace_id
- `PromptStats`: Aggregated usage analytics по времени и проектам
- `ConversionFunnel`: Конфигурация воронок конверсии
- `CustomFunnelConfiguration`: Настраиваемые конфигурации воронок
- `ABTest`: A/B тесты с tracking версий

**Limits & Quotas**
- `UserLimits`: Per-user quota management
- `GlobalLimits`: System-wide default configurations

### API Architecture

#### Public API (`/api/v1/*`)
**Для внешних приложений - интеграция с промптами**

- `GET /api/v1/check-api-key`: Проверка валидности API ключа
- `POST /api/v1/get-prompt`: Получение промпта по slug
  - Поддержка версионирования
  - A/B тестирование (автоматическое распределение)
  - Trace ID для отслеживания
- `POST /api/v1/events`: Отправка одного события
- `POST /api/v1/events/batch`: Batch отправка событий (до 100)

#### Internal API (`/internal/*`)
**Для управления платформой - не публикуется в Swagger**

- `/internal/api/auth/*`: Аутентификация и авторизация
- `/internal/api/prompts/*`: Управление промптами
- `/internal/api/workspaces/*`: Управление workspace
- `/internal/api/analytics/*`: Аналитика и метрики
- `/internal/api/ab-tests-simple/*`: A/B тестирование
- `/internal/api/conversion-funnels/*`: Воронки конверсии
- `/internal/api/event-definitions/*`: Управление схемами событий
- `/internal/api/llm/*`: LLM провайдеры и тестирование
- `/internal/api/product-api-keys/*`: Управление API ключами
- `/internal/api/api-usage/*`: Логи использования API
- `/internal/api/statistics/*`: Статистика и отчеты

#### Admin Interface (`/admin`)
- **SQLAdmin integration**: Direct database management
- **User lifecycle management**: Create/update/delete с safety checks
- **System configuration**: Global limits и provider settings
- **Cross-workspace analytics**: Enterprise-wide usage insights
- **Data export capabilities**: Compliance и reporting tools

### Middleware Stack

#### Security Middleware
- **ErrorHandlerMiddleware**: Централизованная обработка ошибок
- **SecurityMiddleware**: Защита от основных уязвимостей
- **TrustedHostMiddleware**: Валидация хостов
- **SwaggerAuthMiddleware**: Защита admin документации
- **CORS Middleware**: Cross-origin security

#### Business Logic Middleware
- **ProductAPILoggingMiddleware**: Логирование всех API запросов
- **RateLimitMiddleware**: Rate limiting через Redis
- **SessionMiddleware**: Управление сессиями для admin

### Services Layer

#### Core Services
- **analytics.py**: Обработка событий и аналитика
- **conversion_calculator.py**: Расчет метрик воронок
- **event_logger.py**: Логирование событий
- **limits.py**: Управление квотами и лимитами
- **redis.py**: Redis caching и session management
- **scheduler.py**: Фоновые задачи (агрегация статистики)
- **statistics.py**: Статистика и отчеты

#### Check API Key
```http
GET /api/v1/check-api-key
Authorization: Bearer xr2_prod_xxx
```

Response:
```json
{
  "ok": true,
  "user": "your_username"
}
```

#### Get Prompt
```http
POST /api/v1/get-prompt
Authorization: Bearer xr2_prod_xxx
Content-Type: application/json

{
  "slug": "customer-support",
  "source_name": "web_app",
  "version_number": 1,  // optional
  "status": "production"  // optional
}
```

Response:
```json
{
  "slug": "customer-support",
  "system_prompt": "You are a helpful assistant...",
  "user_prompt": "Help the customer with: {issue}",
  "trace_id": "evt_abc123_1634567890_xyz",
  "version_number": 1,
  "ab_test_id": "test_123",  // если активен A/B тест

}
```

#### Track Event
```http
POST /api/v1/events
Authorization: Bearer xr2_prod_xxx
Content-Type: application/json

{
  "trace_id": "evt_abc123_1634567890_xyz",
  "event_name": "user_signup",
  "category": "conversion",
  "fields": {

```

### Integration Examples

#### Simple cURL Integration
```bash
curl -X POST https://xr2.uk/api/v1/get-prompt \
  -H "Authorization: Bearer xr2_prod_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "slug": "customer-support",
    "source_name": "web_app"
  }'
```

#### Webhook Integration
```javascript
// Отправка события после получения промпта
const response = await fetch('https://xr2.uk/api/v1/get-prompt', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer xr2_prod_xxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    slug: 'onboarding',
    source_name: 'mobile_app'
  })
});

const { trace_id } = await response.json();

// Позже, когда пользователь завершил регистрацию
await fetch('https://xr2.uk/api/v1/events', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer xr2_prod_xxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    trace_id: trace_id,
    event_name: 'user_signup',
    category: 'conversion',
    fields: {
      user_id: 'user123',
      source: 'mobile_app'
    }
  })
});
```
