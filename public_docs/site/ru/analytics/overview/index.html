Обзор аналитики

Аналитика xR2 позволяет измерять влияние ваших AI-промптов на бизнес. Отслеживайте действия пользователей, создавайте воронки конверсии и понимайте, какие промпты приносят реальные результаты.

Почему аналитика важна

Без аналитики вы действуете вслепую:

  • Увеличил ли новый промпт количество регистраций?
  • Какая версия промпта конвертирует лучше?
  • На каком этапе AI-взаимодействия пользователи уходят?

xR2 отвечает на эти вопросы с помощью данных.

Как это работает

1. Пользователь запрашивает промпт через API
2. xR2 возвращает промпт + уникальный trace_id
3. Ваше приложение использует промпт с LLM
4. Когда пользователь совершает конверсию, отправьте событие с trace_id
5. xR2 связывает событие с промптом
6. Анализируйте в дашборде

Trace ID

Каждый запрос промпта возвращает trace_id:

{
  "slug": "onboarding-assistant",
  "system_prompt": "...",
  "trace_id": "evt_abc123_1234567890_xyz"
}

Этот идентификатор — ключ к атрибуции. Сохраните его и включайте при отслеживании событий.

Производительность промптов

Метрика Описание
Запросы Общее количество API-вызовов к этому промпту
Уникальные пользователи Количество уникальных user_id

Сценарии использования

Электронная коммерция

Отслеживание покупок с помощью AI:

Промпт: product-recommender
События: product_viewed → added_to_cart → purchase_completed
Измерение: Выручка на версию промпта

Онбординг в SaaS

Отслеживание завершения регистрации:

Промпт: onboarding-assistant
События: signup_started → profile_completed → first_action
Измерение: Коэффициент активации по промпту

Служба поддержки

Отслеживание качества решений:

Промпт: support-bot
События: ticket_opened → ai_response_sent → issue_resolved
Измерение: Коэффициент решения, оценка CSAT

Генерация контента

Отслеживание вовлечённости:

Промпт: blog-writer
События: content_generated → content_published → content_shared
Измерение: Процент распространения по версии промпта

Начало работы

  1. Определите события — Какие действия важны для вашего бизнеса?
  2. Инструментируйте код — Отправляйте события с trace_id
  3. Создайте воронки — Соедините события в пути конверсии
  4. Анализируйте и улучшайте — Используйте данные для улучшения промптов
