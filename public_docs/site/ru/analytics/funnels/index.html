Воронки конверсии

Воронки помогают понять, как пользователи проходят через последовательность шагов. Смотрите, где они конвертируются и где уходят.

Что такое воронка?

Воронка — это последовательность событий, которые пользователи должны завершить:

Шаг 1: signup_started      → 1 000 пользователей (100%)
Шаг 2: email_verified      →   800 пользователей (80%)
Шаг 3: profile_completed   →   500 пользователей (50%)
Шаг 4: first_purchase      →   200 пользователей (20%)

Каждый шаг показывает:

  • Сколько пользователей достигло его
  • Коэффициент конверсии с предыдущего шага
  • Общую конверсию от начала

Создание воронки

  1. Перейдите в Аналитика → Воронки
  2. Нажмите + Новая воронка
  3. Настройте:
    • Название: Описательное название (например, "Воронка онбординга")
    • Источник: Выберите начальную точку
    • Шаги: Добавьте события по порядку
  4. Нажмите Сохранить

Типы источников воронки

Источник воронки определяет, что считается "входом" в воронку:

Тип источника Описание
Запросы промптов Пользователи, получившие определённый промпт через API (вызовы get-prompt)
Событие Пользователи, вызвавшие определённое событие

Совет: Используйте "Запросы промптов" как источник, чтобы измерить, сколько пользователей, получивших ваш промпт, продолжили конвертироваться. Это наиболее распространённая настройка для измерения эффективности промптов.

Добавление шагов

Для каждого шага:

  1. Нажмите + Добавить шаг
  2. Выберите событие из выпадающего списка
  3. Опционально добавьте фильтры (например, учитывать только события с value > 10)
  4. Повторите для всех шагов

Пример: Воронка электронной коммерции

Воронка: Процесс покупки

Шаг 1: product_viewed
Шаг 2: added_to_cart
Шаг 3: checkout_started
Шаг 4: purchase_completed

Визуализация воронки

Воронка отображается в виде визуальной диаграммы:

┌─────────────────────────────────────────┐
│ product_viewed                    1,000 │ 100%
├─────────────────────────────────────────┤
│ added_to_cart                       400 │ 40%  ↓60% отток
├─────────────────────────────────────────┤
│ checkout_started                    200 │ 50%  ↓50% отток
├─────────────────────────────────────────┤
│ purchase_completed                  150 │ 75%  ↓25% отток
└─────────────────────────────────────────┘

Общая конверсия: 15%

Метрики воронки

Метрика Описание
Вошли Пользователи, завершившие шаг 1
Сконвертировались Пользователи, завершившие все шаги
Общая конверсия Сконвертировавшиеся / Вошедшие × 100%
Коэффициент оттока 100% - Конверсия шага
Время до конверсии Среднее время от первого до последнего шага

Фильтрация воронок

По промпту

Смотрите эффективность воронки для конкретного промпта:

  1. Выберите фильтр Промпт
  2. Выберите промпт
  3. Опционально отфильтруйте по версии

По диапазону дат

Анализируйте конкретные периоды времени:

  • Последние 7 дней
  • Последние 30 дней
  • Произвольный диапазон

По сегменту пользователей

Фильтруйте по атрибутам пользователей:

  • Паттерн User ID
  • Свойства сессии
  • Значения метаданных

Анализ оттока

Когда вы видите высокий отток между шагами:

Шаг 1 → Шаг 2 (60% отток)

Вопросы для анализа:

  • Не запутывает ли пользователей ответ AI?
  • Понятно ли следующее действие?
  • Есть ли технические проблемы?

Действия:

  • Проверьте содержание промпта
  • Просмотрите логи ошибок
  • Протестируйте процесс самостоятельно

Средние шаги (высокий отток)

Вопросы для анализа:

  • Не слишком ли сложен шаг?
  • Есть ли трение в UX?
  • Правильно ли ответ AI направляет пользователей?

Действия:

  • Упростите шаг
  • Улучшите инструкции AI
  • Проведите A/B-тест разных подходов

Сравнение воронок

По версии промпта

Сравнивайте, как работают разные версии промптов:

Воронка: Онбординг

Промпт v1:
  signup_started → signup_completed: 45%

Промпт v2:
  signup_started → signup_completed: 62%

Победитель: v2 (+17% улучшение)

По периоду времени

Сравнивайте эффективность во времени:

Прошлая неделя:  Общая конверсия: 15%
Эта неделя:      Общая конверсия: 18%
Изменение:       +3% улучшение

По A/B-тесту

Смотрите эффективность воронки по вариантам теста:

Вариант A: 12% общая конверсия
Вариант B: 18% общая конверсия

Сценарии использования воронок

Оптимизация онбординга

Шаги:
1. signup_started
2. email_verified
3. profile_completed
4. first_feature_used
5. subscription_started

Цель: Максимизировать платные подписки

Качество поддержки

Шаги:
1. support_requested
2. ai_response_viewed
3. follow_up_asked (обратный показатель — чем меньше, тем лучше)
4. issue_resolved
5. positive_feedback

Цель: Решать проблемы за один ответ AI

Вовлечённость в контент

Шаги:
1. content_generated
2. content_edited
3. content_approved
4. content_published
5. content_shared

Цель: Максимизировать контент, которым делятся

Лучшие практики

1. Начните просто

Начните с 3-4 ключевых шагов:

signup → activation → conversion

Добавьте детализацию позже при необходимости.

2. Определите чёткие шаги

Каждый шаг должен быть:

  • Единственным, отдельным действием
  • Измеримым через события
  • Значимым для бизнеса

3. Порядок имеет значение

Шаги должны идти в логическом порядке:

product_viewed → added_to_cart → purchased
purchased → product_viewed → added_to_cart

4. Сегментируйте для инсайтов

Не смотрите только на общие числа. Сегментируйте по:

  • Типу пользователя (новые vs вернувшиеся)
  • Источнику трафика
  • Типу устройства
  • Географии

Следующие шаги

  • A/B-тестирование — Тестируйте, какие промпты улучшают конверсию воронки
  • Отслеживание событий — Убедитесь, что все шаги воронки отслеживаются
