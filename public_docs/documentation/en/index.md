# Welcome to xR2

**xR2** is an AI prompt management platform that lets you update prompts without code deployments, run A/B tests, and measure business impact with built-in analytics.

Website: [https://xr2.uk](https://xr2.uk)

## Why xR2?

Traditional prompt management is painful:

- Every prompt change requires a code deployment
- No way to test different prompt versions
- Impossible to measure which prompts drive conversions
- Most current solutions are designed for developers, not product managers or enthusiasts

**xR2 solves this:**

- **Zero-code updates** — Change prompts instantly without touching your codebase
- **Version control** — Git-like workflow with drafts, testing, and production statuses
- **A/B testing** — Compare prompt versions and pick the winner based on data. You can run tests without a developer ;-)
- **Analytics** — Track events, build funnels, measure ROI of your prompts

## What if I'm not a developer or product owner?

No problem. We've thought about you too and created convenient SDKs for use with n8n, Make, Zapier, and more.
If you've just automated your social media management - we'll make your life much easier)
