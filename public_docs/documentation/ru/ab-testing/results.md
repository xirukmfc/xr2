# Измерение результатов

Узнайте, как анализировать результаты A/B-тестов и принимать решения на основе данных.

## Панель результатов

Перейдите в **Аналитика** → **A/B-тесты** → Выберите тест.

### Раздел обзора

| Метрика | Описание |
|---------|----------|
| **Статус** | Running, Completed, Cancelled |
| **Длительность** | Как долго тест работает |
| **Всего запросов** | Суммарные запросы для обоих вариантов |
| **Запросов по варианту** | Распределение между A и B |

### Сравнение производительности

```
┌─────────────────────────────────────────────────┐
│              Version A    Version B    Diff     │
├─────────────────────────────────────────────────┤
│ Requests         2,450        2,550             │
│ Conversions        294          357             │
│ Conv. Rate       12.0%        14.0%   +16.7%   │
│ Confidence                              94%     │
└─────────────────────────────────────────────────┘
```

## Ключевые метрики

### Показатель конверсии

Процент пользователей, которые выполнили событие успеха:

```
Conversion Rate = Conversions / Requests × 100%
```

**Пример:**
- Версия A: 294 конверсии / 2 450 запросов = 12,0%
- Версия B: 357 конверсий / 2 550 запросов = 14,0%

### Относительное улучшение

Насколько тестовый вариант лучше контрольного:

```
Improvement = (B - A) / A × 100%
```

**Пример:**
```
(14.0% - 12.0%) / 12.0% = +16.7% improvement
```

### Уровень достоверности

Насколько мы уверены, что разница реальна (не случайность):

| Достоверность | Интерпретация |
|---------------|---------------|
| < 80% | Незначимо, нужно больше данных |
| 80-90% | Слабые доказательства |
| 90-95% | Умеренные доказательства |
| 95-99% | Сильные доказательства |
| > 99% | Очень сильные доказательства |

**Отраслевой стандарт**: 95% достоверность перед объявлением победителя.

## Чтение результатов

### Явный победитель

```
Version A: 10.2%
Version B: 14.8%
Confidence: 98%

→ Version B wins decisively
```

**Действие**: Разверните версию B

### Нет разницы

```
Version A: 12.1%
Version B: 12.3%
Confidence: 52%

→ No meaningful difference
```

**Действие**: Оставьте текущую версию (A), тестируйте что-то другое

### Неоднозначно

```
Version A: 11.5%
Version B: 13.2%
Confidence: 78%

→ B looks better but not confident
```

**Действие**: Продолжайте тест или увеличьте размер выборки

## Анализ за пределами конверсии

### Сегментный анализ

Смотрите на результаты по сегментам пользователей:

| Сегмент | Версия A | Версия B | Победитель |
|---------|----------|----------|------------|
| Новые пользователи | 8% | 12% | B (+50%) |
| Возвращающиеся | 15% | 14% | A (+7%) |
| Мобильные | 10% | 13% | B (+30%) |
| Десктоп | 12% | 11% | A (+9%) |

**Вывод**: B работает лучше для новых и мобильных пользователей. Рассмотрите разные промпты для разных сегментов.

### Анализ по времени

Проверьте, изменяются ли результаты со временем:

```
Week 1: A=11%, B=14%
Week 2: A=12%, B=13%
Week 3: A=12%, B=12%
```

**Вывод**: Преимущество B уменьшилось со временем (эффект новизны).

### Влияние на выручку

Если отслеживаете денежную ценность:

```
Version A: $45.20 avg order value
Version B: $52.80 avg order value
Improvement: +16.8% revenue per user
```

## Принятие решений

### Когда объявлять победителя

Объявляйте победителя, когда:
- Достоверность >= 95%
- Размер выборки соответствует минимальным требованиям
- Результаты стабильны во времени
- Бизнес-влияние значимо

Не объявляйте победителя, когда:
- Достоверность < 90%
- Размер выборки слишком мал
- Результаты колеблются
- Разница незначительна (< 1%)

## После теста

### Если B побеждает

1. Разверните версию B
2. Задокументируйте выводы
3. Запланируйте следующий тест (можно ли B сделать ещё лучше?)

### Если A побеждает

1. Оставьте версию A
2. Проанализируйте, почему B не сработал
3. Сформируйте новую гипотезу
4. Протестируйте другой подход

### Если ничья

1. Оставьте текущую версию
2. Тестируйте что-то более отличающееся
3. Подумайте, стоит ли изменение усилий

## Устранение неполадок

### Результаты не соответствуют ожиданиям

- Проверьте, работает ли отслеживание событий
- Убедитесь, что trace_id связаны
- Поищите ошибки в любой из версий
- Проверьте внешние факторы (сезонность, сбои)

### Показатель конверсии равен нулю

- События не отслеживаются
- Выбрано неверное событие успеха
- Проблемы с API-ключом
- Проверьте вкладку «Недавние события»

### Результаты кажутся неправильными

- Размер выборки слишком мал
- Длительность теста слишком короткая
- Внешние факторы влияют на результаты
- Проверьте качество данных
