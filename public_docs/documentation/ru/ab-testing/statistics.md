# Статистическая значимость

Понимание статистической значимости помогает принимать уверенные решения по результатам A/B-тестов.

## Что такое статистическая значимость?

Когда вы проводите A/B-тест, вы видите разницу между версиями:
- Версия A: 12% конверсия
- Версия B: 14% конверсия

Но эта разница **реальна** или просто **случайность**?

Статистическая значимость отвечает: «Насколько мы уверены, что B действительно лучше A?»

## Проблема случайности

Представьте, что вы подбрасываете монету 10 раз:
- Вы можете получить 6 орлов, 4 решки
- Значит ли это, что монета смещена?
- Нет — при всего 10 подбрасываниях это нормальная вариация

То же самое применимо к A/B-тестам:
- Маленькая выборка → результаты могут вводить в заблуждение
- Большая выборка → результаты надёжны

## Объяснение уровня достоверности

Уровень достоверности (например, 95%) означает:

> «Если бы мы провели этот тест 100 раз без реальной разницы, мы бы увидели такую большую разницу только 5 раз.»

Другими словами:
- **95% достоверность** = 5% вероятность, что результат случаен
- **99% достоверность** = 1% вероятность, что результат случаен

### Отраслевые стандарты

| Достоверность | Сценарий использования |
|---------------|------------------------|
| 80% | Раннее исследование, быстрые решения |
| 90% | Стандартные продуктовые решения |
| **95%** | **Отраслевой стандарт** |
| 99% | Решения с высокими ставками |
| 99.9% | Критические изменения (платежи, безопасность) |

## Как xR2 вычисляет значимость

xR2 использует **двухвыборочный z-тест для долей**:

```
For each variant:
- p₁ = conversions_A / requests_A
- p₂ = conversions_B / requests_B

Calculate:
- Pooled proportion
- Standard error
- Z-score
- P-value
- Confidence level = 1 - p-value
```

Вам не нужно делать эти расчёты — xR2 показывает уровень достоверности автоматически.

## Требования к размеру выборки

### Минимальный размер выборки

Требуемый размер выборки зависит от:

1. **Базовый показатель конверсии** — ваш текущий показатель конверсии
2. **Минимальный обнаруживаемый эффект** — наименьшее улучшение, которое стоит обнаружить
3. **Уровень достоверности** — насколько вы хотите быть уверены
4. **Статистическая мощность** — способность обнаружить реальные различия (обычно 80%)

### Калькулятор размера выборки

| Базовый показатель | Улучшение 5% | Улучшение 10% | Улучшение 20% |
|--------------------|--------------|---------------|---------------|
| 5% | 31 000 | 8 000 | 2 000 |
| 10% | 15 000 | 4 000 | 1 000 |
| 20% | 6 000 | 1 600 | 400 |

**Пример**: Если ваша текущая конверсия 10% и вы хотите обнаружить 10% улучшение (10% → 11%), вам нужно ~4 000 образцов на вариант.

### Быстрые эмпирические правила

- **Минимум**: 1 000 образцов на вариант
- **Стандарт**: 2 500-5 000 на вариант
- **Высокая достоверность**: 10 000+ на вариант

## Интерпретация результатов

### Сильные доказательства (>= 95%)

```
Confidence: 97%
Version A: 12.1%
Version B: 14.8%
```

Безопасно заключить: B лучше A

### Слабые доказательства (80-95%)

```
Confidence: 88%
Version A: 12.1%
Version B: 13.5%
```

Действуйте с осторожностью:
- B может быть лучше
- Может быть случайная вариация
- Рассмотрите продление теста

### Нет доказательств (<80%)

```
Confidence: 65%
Version A: 12.1%
Version B: 12.8%
```

Нельзя сделать никаких выводов:
- Разница, вероятно, случайна
- Нужно больше образцов
- Или версии действительно равны

## Частые ошибки

### 1. Слишком ранняя остановка

**Неправильно:**
```
Day 1: B is winning 60% vs 40%! Ship it!
```

Ранние результаты ненадёжны. Тест, показывающий победу B на 20% в первый день, может закончиться победой A на 5%.

**Правильно:** Дождитесь запланированного размера выборки или уровня достоверности.

### 2. Подглядывание и принятие решений

**Неправильно:**
```
Check results daily.
When B looks good, stop the test.
When A looks good, keep running.
```

Это резко увеличивает количество ложноположительных результатов.

**Правильно:** Установите размер выборки заранее, не подглядывайте, анализируйте в конце.

### 3. Игнорирование практической значимости

**Неправильно:**
```
A: 10.00%
B: 10.05%
Confidence: 99%

Ship B because it's statistically significant!
```

Улучшение на 0,05% может не стоить сложности.

**Правильно:** Подумайте, является ли разница **практически** значимой.

### 4. Множественные сравнения

**Неправильно:**
```
Test 20 variations.
One shows 95% confidence.
Ship it!
```

При 20 вариациях с 95% достоверностью ожидается 1 ложноположительный результат.

**Правильно:** Делайте поправку на множественные сравнения или тестируйте меньше вариаций.

## Понимание P-значений

**P-значение** — это вероятность увидеть результаты такого масштаба, если реальной разницы нет.

| P-значение | Достоверность | Интерпретация |
|------------|---------------|---------------|
| 0.20 | 80% | Слабые доказательства |
| 0.10 | 90% | Умеренные доказательства |
| **0.05** | **95%** | **Стандартный порог** |
| 0.01 | 99% | Сильные доказательства |
| 0.001 | 99.9% | Очень сильные доказательства |

**Меньшее p-значение = больше уверенности, что разница реальна**

## Доверительные интервалы

Вместо только точечной оценки доверительные интервалы показывают диапазон вероятных значений:

```
Version B improvement: 16.7%
95% Confidence Interval: [8.2%, 25.1%]
```

Это означает:
- Лучшая оценка: B лучше на 16,7%
- Мы на 95% уверены, что истинное улучшение между 8,2% и 25,1%
- Как минимум, B, вероятно, лучше на 8,2%

### Интерпретация доверительных интервалов

**Широкий интервал** (например, [-5%, +40%]):
- Высокая неопределённость
- Нужно больше образцов

**Узкий интервал** (например, [14%, 19%]):
- Высокая определённость
- Надёжный результат

**Интервал пересекает ноль** (например, [-2%, +8%]):
- Нельзя заключить, что B лучше
- Может быть хуже, равен или лучше

## Анализ мощности

**Статистическая мощность** = вероятность обнаружения реального эффекта.

- Низкая мощность (50%) → Можете пропустить реальные улучшения
- Стандартная мощность (80%) → Хороший баланс
- Высокая мощность (90%+) → Редко пропускаете улучшения

### Недостаточно мощные тесты

```
Actual improvement: 10%
Sample size: 500
Power: 40%

Result: "No significant difference"
```

Тест был слишком мал, чтобы обнаружить реальное 10% улучшение.

### Правильно мощные тесты

```
Actual improvement: 10%
Sample size: 5,000
Power: 90%

Result: "B is significantly better (12% improvement, 96% confidence)"
```

## Принятие решений

### Фреймворк принятия решений

| Достоверность | Размер эффекта | Решение |
|---------------|----------------|---------|
| >= 95% | Большой | Разверните B |
| >= 95% | Маленький | Подумайте, стоит ли оно того |
| 80-95% | Большой | Продлите тест или разверните B |
| 80-95% | Маленький | Продлите тест |
| < 80% | Любой | Продлите тест или откажитесь |

### Когда результаты неоднозначны

Варианты:
1. **Продлите тест** — Больше образцов = больше достоверности
2. **Примите неопределённость** — Разверните, если риск низкий
3. **Откажитесь от теста** — Если разницы, вероятно, нет
4. **Тестируйте более значительные изменения** — Тонкие изменения трудно обнаружить

## Практические советы

### 1. Рассчитайте размер выборки до начала

Используйте таблицу выше или онлайн-калькуляторы для определения необходимых образцов.

### 2. Установите правило остановки

Перед началом:
- «Мы будем тестировать до 5 000 образцов ИЛИ 95% достоверности»
- Придерживайтесь этого

### 3. Не выбирайте выборочно

Если вы проводите много тестов, некоторые покажут ложноположительные результаты. Не отчитывайтесь только о «победах».

### 4. Учитывайте бизнес-влияние

1% улучшение с 99% достоверностью может значить меньше, чем 20% улучшение с 90% достоверностью.

### 5. Документируйте и учитесь

Даже «неудачные» тесты чему-то учат. Документируйте все результаты.

## Резюме

| Концепция | Ключевой момент |
|-----------|-----------------|
| **Статистическая значимость** | Насколько достоверна разница |
| **Уровень достоверности** | Отраслевой стандарт — 95% |
| **Размер выборки** | Больше образцов = надёжнее результаты |
| **P-значение** | Меньше = больше достоверности |
| **Доверительный интервал** | Диапазон вероятных истинных значений |
| **Мощность** | Способность обнаружить реальные эффекты |

В случае сомнений: **больше образцов, выше достоверность, больший эффект**.
