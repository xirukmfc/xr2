# Обзор редактора промптов

Редактор промптов xR2 — это мощный визуальный инструмент для создания, редактирования и управления AI-промптами. Он предоставляет все необходимое для итеративной работы с промптами без изменения кодовой базы.

## Структура редактора

Редактор разделен на две основные области:
![Редактор промпта](../../images/prompt-editor.png)

### Левая панель — Метаданные и основные настройки

- **Основные настройки** — Где можно задать описание, название или slug
- **Переменные** — Определение и управление динамическими переменными
- **Теги** — Организация промптов с помощью цветных меток
- **История версий** — Просмотр и восстановление предыдущих версий
- **Статистика производительности** — Просмотр метрик использования

### Центральная панель — Редактор контента

Редактор кода на базе Monaco (такой же, как в VS Code) с:

- Подсветкой синтаксиса
- Тремя вкладками: System, User промпты
- Полноэкранным режимом
- Настройкой размера шрифта
- Функцией копирования

## Типы промптов

Каждый промпт может содержать два компонента:

| Тип | Назначение | Пример |
|------|---------|---------|
| **System Prompt** | Определяет поведение и личность AI | "You are a helpful assistant that speaks formally." |
| **User Prompt** | Шаблон для пользовательского ввода с переменными | "Help {{user_name}} with: {{question}}" |

## Ключевые возможности

### Визуальное обнаружение переменных

Редактор автоматически обнаруживает переменные в формате `{{variable_name}}` и отображает их в левой панели для настройки.

### Полноэкранный режим

Нажмите на иконку полноэкранного режима, чтобы развернуть редактор на весь экран. Возможности:

- Среда редактирования без отвлекающих факторов
- Сворачиваемая панель переменных справа
- Управление размером шрифта (10px-32px)
- Подсветка синтаксиса Markdown
- Режим предпросмотра отрендеренного контента
- Копирование всего содержимого
- Горячие клавиши: `⌘S` для сохранения, `Escape` для выхода

### Тестирование в реальном времени

Тестируйте промпты прямо в редакторе с любым LLM-провайдером (OpenAI, Anthropic, Google и др.) и наблюдайте потоковые ответы.

![Тестирование ИИ](../../images/ai-test.png)

### Конвейер развертывания

Мгновенное развертывание версий в продакшен. Отслеживание кто, что и когда развернул.

### Публикация версий

Делитесь конкретными версиями промптов с членами команды или внешними заинтересованными сторонами:

1. Откройте версию, которой хотите поделиться
2. Нажмите кнопку **Share** (находится в левом части редактора в списке версий)
3. Генерируется уникальная публичная ссылка
4. Получатели могут просматривать (только для чтения):
    - Содержимое промпта (system, user, assistant)
    - Определения переменных
    - Метаданные (кто создал, даты)
5. Ссылки можно деактивировать

![Поделиться промптом](../../images/prompt-share.png)


## Горячие клавиши

| Сочетание       | Действие                   |
|-----------------|----------------------------|
| `⌘S` / `Ctrl+S` | Сохранить изменения        |
| `⌘P` / `Ctrl+P` | Деплой и Раздеплой промпта |
