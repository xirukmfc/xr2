# API Логи

Страница API Logs предоставляет полную историю всех API-запросов к вашему воркспейсу xR2. Отслеживайте использование, отлаживайте интеграции и мониторьте активность в реальном времени.

## Доступ к API Logs

Перейдите в **API Logs** в боковом меню или напрямую на [xr2.uk/logs](https://xr2.uk/logs).

## Что логируется

Записываются все запросы к пользовательским API:

### Запросы получения промптов

Каждый вызов `/api/v1/get-prompt`:

- Время запроса
- Запрошенный slug промпта
- Source name
- Статус ответа
- Возвращённая версия промпта
- Сгенерированный `trace_id`

### Запросы отслеживания событий

Каждый вызов `/api/v1/events`:

- Время запроса
- Название события
- Source name
- Связанный `trace_id`
- Данные события (value, currency, metadata)
- Статус ответа

## Детали записи лога

Нажмите на любую запись, чтобы увидеть полную информацию:

### Информация о запросе

- **Время**: Когда был сделан запрос
- **Endpoint**: Вызванный API endpoint
- **Метод**: HTTP метод (POST)
- **Source**: `source_name` из запроса
- **IP-адрес**: Источник запроса

### Тело запроса

Полный JSON payload:

```json
{
  "slug": "customer-support",
  "source_name": "web_app",
  "variables": {
    "customer_name": "John"
  }
}
```

### Тело ответа

Полный JSON ответ:

```json
{
  "slug": "customer-support",
  "system_prompt": "You are a helpful assistant...",
  "user_prompt": "Help {{customer_name}} with...",
  "trace_id": "evt_abc123_1234567890_xyz"
}
```

### Статус ответа

- **200**: Успешный запрос
- **400**: Неверный запрос (отсутствуют поля, неверный slug)
- **401**: Ошибка аутентификации
- **404**: Промпт не найден
- **500**: Ошибка сервера

## Фильтрация логов

Фильтруйте логи для поиска конкретных запросов:

- **Диапазон дат**: Выберите начальную и конечную даты
- **Endpoint**: Фильтр по API endpoint
- **Промпт**: Фильтр по slug промпта
- **Source**: Фильтр по source_name
- **Статус**: Показать только ошибки или успешные

## Сценарии использования

### Отладка интеграций

Когда интеграция не работает:

1. Сделайте тестовый запрос из приложения
2. Найдите его в API Logs
3. Проверьте тело запроса на ошибки
4. Проверьте ответ

### Мониторинг использования

Отслеживайте, как используются ваши промпты:

- Какие промпты вызываются чаще всего
- Пиковое время использования
- Распределение по источникам запросов

### Аудит

API Logs предоставляют полный аудит:

- Кто обращался к каким промптам
- Когда отслеживались события
- Полная история запросов/ответов
