# Добро пожаловать в xR2

**xR2** — это платформа управления AI-промптами, которая позволяет обновлять промпты без деплоя кода, проводить A/B тесты и измерять бизнес-результаты с помощью встроенной аналитики.

Сайт: [https://xr2.site](https://xr2.site)

## Зачем нужен xR2?

Традиционное управление промптами — это боль:

- Каждое изменение промпта требует деплоя кода
- Нет возможности тестировать разные версии промптов
- Невозможно измерить, какие промпты приводят к конверсиям
- Да и в целом большинство текущих решений заточены под разработчиков, а не продуктовиков или обычных пользователей интузиастов

**xR2 решает эти проблемы:**

- **Обновления без кода** — Меняйте промпты мгновенно, не трогая кодовую базу
- **Контроль версий** — Git-подобный воркфлоу с черновиками, тестированием и продакшн-статусами
- **A/B тестирование** — Сравнивайте версии промптов и выбирайте победителя на основе данных. Вы можете запустить тесты без работчика ;-)
- **Аналитика** — Отслеживайте метрики, стройте воронки, измеряйте ROI ваших промптов

## А если я не разработчик и не продакт оунер?

Так не беда. Мы тоже подумали о вас сделали удобные SDK для использования в n8n, make, zapier и тд
