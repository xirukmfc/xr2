# Клиентский путь (Customer Journey) для xR2

## Задача №1: Как быстро начать использовать сервис?

### 🎯 Цель
Пользователь должен получить **первый работающий промпт через API** за **менее 5 минут** после регистрации.

---

## 📊 Анализ текущего состояния

### Что уже есть:
✅ Регистрация через Google OAuth (1 клик)  
✅ Регистрация через email/password  
✅ Автоматическое создание workspace при регистрации  
✅ Редирект на `/prompts` после логина  
✅ Возможность создать промпт через UI  
✅ API endpoint `/api/v1/get-prompt/{slug}` для получения промптов  

### Что отсутствует:
❌ Onboarding flow для новых пользователей  
❌ Быстрый старт (Quick Start) для разных сегментов ЦА  
❌ Готовые примеры промптов  
❌ Инструкции по интеграции с Make/n8n  
❌ Генерация API ключа в onboarding  
❌ Тестовый промпт "из коробки"

## 🎯 Клиентский путь для разных сегментов ЦА

### Сегмент 1: Пользователи Make/n8n (чайники AI)

**Их потребности:**
- Хотят быстро подключить промпт к своему workflow
- Не хотят разбираться в сложных настройках
- Нужны готовые примеры и инструкции
- Хотят видеть результат сразу

**Идеальный путь:**
1. **Регистрация** (Google OAuth - 1 клик)
2. **Welcome screen** с выбором платформы (Make/n8n/Zapier/Bubble)
3. **Quick Start Wizard:**
   - Выбор типа промпта (email, поддержка, контент и т.д.)
   - Создание первого промпта из шаблона
   - Автоматическая генерация API ключа
   - Показ инструкции по интеграции с выбранной платформой
4. **Success screen** с:
   - Готовым API endpoint
   - Скопированным API ключом
   - Ссылкой на инструкцию для Make/n8n
   - Кнопкой "Test in Make/n8n" (открывает их платформу)

**Время до первого промпта:** 2-3 минуты

---

### Сегмент 2: Product Managers / Product Owners

**Их потребности:**
- Хотят понять ценность продукта быстро
- Нужны примеры использования
- Хотят увидеть аналитику и ROI
- Нужны инструменты для A/B тестирования

**Идеальный путь:**
1. **Регистрация** (Google OAuth)
2. **Onboarding с демо:**
   - Показ готового промпта с примерами использования
   - Демонстрация версионирования
   - Показ аналитики на примере
   - Объяснение A/B тестирования
3. **Создание первого промпта:**
   - Выбор из шаблонов или создание с нуля
   - Настройка переменных
   - Тестирование промпта прямо в интерфейсе
4. **Интеграция:**
   - Показ API endpoint
   - Генерация API ключа
   - Примеры кода для разных языков

**Время до первого промпта:** 3-5 минут

---

### Сегмент 3: Продуктовые команды / Разработчики

**Их потребности:**
- Нужны технические детали
- Хотят быстро интегрировать в существующий код
- Нужны SDK и примеры кода
- Хотят понять архитектуру

**Идеальный путь:**
1. **Регистрация** (Google OAuth или email)
2. **Технический Quick Start:**
   - Показ API документации
   - Примеры интеграции (cURL, Python, JS)
   - Создание тестового промпта
   - Генерация API ключа
3. **Создание первого промпта:**
   - Создание промпта через UI или API
   - Тестирование через API
   - Просмотр логов запросов
4. **Интеграция в проект:**
   - Скачивание SDK (если есть)
   - Примеры кода для их стека
   - Настройка окружений (dev/staging/prod)

**Время до первого промпта:** 5-7 минут

## 🚀 Рекомендуемый универсальный путь (MVP)

### Вариант 1: Минимальный Quick Start (можно сделать быстро)

**После регистрации → Welcome Screen:**

```
┌─────────────────────────────────────────┐
│  Welcome to xR2! 🎉                    │
│                                         │
│  Let's create your first prompt in     │
│  3 simple steps:                       │
│                                         │
│  1. Choose a template                  │
│  2. Customize it                       │
│  3. Get your API endpoint              │
│                                         │
│  [Start Quick Start]                   │
└─────────────────────────────────────────┘
```

**Шаг 1: Выбор шаблона**
- Email assistant
- Customer support
- Content generator
- Product recommendations
- Custom (empty)

**Шаг 2: Редактор промпта**
- Monaco editor с предзаполненным шаблоном
- Кнопка "Test" для проверки
- Сохранение

**Шаг 3: Готово!**
- Показ API endpoint: `GET /api/v1/get-prompt/{slug}`
- Генерация API ключа (если еще нет)
- Кнопка "Copy API Key"
- Ссылки на:
  - Документацию API
  - Интеграции (Make/n8n)
  - Примеры кода

**Время:** 2-3 минуты

---

**После регистрации → Выбор платформы:**

1. Показ готового шаблона промпта
2. Автоматическое создание промпта

4. Показ инструкции для выбранной платформы
5. Кнопка "Open Make/n8n" с pre-filled данными

**Если выбран "Code":**
- Показ API документации
- Примеры кода
- Создание тестового промпта

## 🎨 UI/UX Рекомендации

### Welcome Screen
- **Дизайн:** Чистый, минималистичный
- **Тон:** Дружелюбный, но профессиональный
- **CTA:** Одна главная кнопка "Start Quick Start"
- **Опции:** Кнопка "Skip" или "Explore Later"

### Quick Start Wizard
- **Прогресс:** Показывать шаги (1/3, 2/3, 3/3)
- **Навигация:** Кнопки "Back" и "Next"
- **Валидация:** Проверка на каждом шаге перед переходом
- **Сохрание:** Автосохранение прогресса

### Success Screen
- **Визуализация:** Чекмарки, анимация успеха
- **Информация:** Четко показать что делать дальше
- **Действия:** Копирование API ключа одной кнопкой
- **Следующие шаги:** Понятные инструкции

## 📊 Метрики успеха

### Time to First Value (TTFV)
- **Цель:** < 5 минут от регистрации до первого работающего промпта
- **Измерение:** Трекинг времени от регистрации до первого API запроса

### Completion Rate
- **Цель:** > 70% пользователей завершают Quick Start
- **Измерение:** Процент пользователей, создавших первый промпт

### API Usage Rate
- **Цель:** > 50% пользователей делают API запрос в первые 24 часа
- **Измерение:** Трекинг API запросов после onboarding
